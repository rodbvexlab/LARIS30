Pill-shaped call-to-action button with a flat hard-edge shadow that flattens on press. Use for the RSVP CTA and any primary action.

```jsx
<Button variant="primary" size="lg">RSVP Now</Button>
<Button variant="ghost">See Details</Button>
```

Variants: `primary` (coral), `secondary` (ink), `ghost` (outline, no shadow). Sizes: `sm`, `md`, `lg`.
