# LARIS 30 — IN FULL COLOR
## Briefing Mestre do Projeto

> Arquivo de referência para Claude Code e demais agentes.
> Este documento consolida as decisões já aprovadas para o convite web dos 30 anos da Larissa.
> O wordmark oficial do projeto é **LARIS 30**.

---

## 1. Visão do Projeto

Criar um convite web interativo, mobile-first e memorável para a comemoração de 30 anos da Larissa, realizada em uma chácara, com estética de **Pool Party + Retro Summer + Y2K Pop + Disco + Editorial Fashion**.

A experiência será acessada principalmente por links enviados via WhatsApp, com prioridade para smartphones, especialmente iPhone/Safari e Android/Chrome.

Objetivos:
- forte direção de arte;
- experiência editorial;
- microinterações e motion controlado;
- leitura simples e rápida;
- RSVP;
- rateio;
- PIX;
- localização;
- FAQ;
- performance mobile.

## 19. Motion System

O Motion System aprovado deve ser preservado na implementação React.

Padrões previstos:
- PageLoadSequence
- ScrollReveal
- StaggerReveal
- StickerPop
- FloatingDisco
- ScrollParallax
- HorizontalMarquee
- AnimatedHeadline
- ButtonTap
- ConfettiBurst
- PIX Success
- RSVP Success

### Regras
Priorizar:
- `transform`
- `opacity`
- `translate`
- `scale`
- `rotate`

Evitar:
- blur animado pesado;
- box-shadow animado;
- canvas persistente;
- partículas infinitas;
- WebGL;
- vídeos pesados;
- scroll hijacking.

### Acessibilidade
Respeitar `prefers-reduced-motion`.
