# LARI 30 — IN FULL COLOR
## Interactive Birthday Invitation / Pool Party

### PROJECT TYPE
Interactive mobile-first web invitation.

### EVENT
30th birthday celebration for Larissa.

### DATE
22 August 2026.

### LOCATION
Pool party at a private chácara.

Exact address will be defined later.

---

# 01. PROJECT GOAL

Design a highly memorable digital birthday invitation that guests will access mainly through WhatsApp on smartphones.

This must NOT look like:
- a SaaS landing page;
- a corporate website;
- a dashboard;
- a generic party template;
- a children's birthday invitation.

The desired experience should feel like:

EDITORIAL DESIGN
+
RETRO SUMMER
+
POOL PARTY
+
Y2K POP
+
DISCO CULTURE
+
FASHION COLLAGE

The result must feel personal, stylish, playful and premium.

---

# 02. CREATIVE CONCEPT

Primary visual concept:

LARI 30
IN FULL COLOR

Secondary identifier:

POOL PARTY

Date signature:

22 · AGO · 2026

Core emotional idea:

Celebrating turning 30 with color, sunlight, pool, friends, music, freedom and personality.

The visual identity should celebrate adulthood without becoming formal.

It should feel youthful but not childish.

---

# 03. ART DIRECTION

The main visual universe combines:

- 60s / 70s radial sunburst graphics;
- Y2K pop visual language;
- chrome disco balls;
- summer colors;
- glossy details;
- editorial photography;
- retro stickers;
- stars and sparkles;
- playful organic shapes;
- subtle vintage print texture;
- oversized typography;
- asymmetric compositions;
- intentional visual overlaps.

The uploaded references are mood references.

Do not literally reproduce a reference.

Create a cohesive original visual system using their shared visual language.

The page should alternate visual atmospheres.

Example:

Hero:

Information:
pool blue or cream.

Dress Code:
full color.

Rateio:

BYOB:

RSVP:
lighter visual breathing space.

Closing:
high-impact coral / pink composition.

The page should have rhythm.

Do not create one continuous rainbow gradient.

# 07. TYPOGRAPHY

Use a strong, expressive display font.

Possible directions:
- Syne
- Archivo Black
- Clash Display
- similar high-impact editorial grotesk

Titles may be:
- uppercase;
- oversized;
- compressed;
- stacked;
- partially overlapping imagery.

## BODY

Use a highly readable geometric sans-serif.

Possible directions:
- Plus Jakarta Sans
- Inter
- Space Grotesk

Body text must remain extremely readable on small smartphone screens.

# 11. SIGNATURE VISUAL ELEMENT

The visual signature of the project should be:

- opening;
or

Disco elements may recur subtly throughout the experience.

---

# 12. MOTION LANGUAGE

Animations must reinforce personality without harming mobile performance.

Recommended:

- slow floating disco balls;
- subtle rotation;
- gentle sticker spring entrances;
- fade + translate section entrances;
- horizontal marquee;
- subtle scale on tap;
- very light parallax;
- celebratory confetti after RSVP;
- visual feedback after copying PIX.

Avoid:

- constant confetti;
- extreme bouncing;
- excessive parallax;
- aggressive scroll hijacking;
- heavy WebGL;
- long loading animations.

Animations should use primarily:
transform
opacity

# 14. MOBILE-FIRST RULES

Primary canvas:

390 × 844

Design first for smartphone.

Consider:

- WhatsApp in-app browser;
- iPhone Safari;
- Android Chrome.

Primary CTA touch target:
minimum approximately 48px high.

Keep essential information readable without zoom.

Avoid desktop-first compositions compressed into mobile.

---

# 15. UI SHAPE LANGUAGE

Prefer:

- large rounded shapes;
- organic visual blocks;
- editorial typography;
- sticker treatment;
- pills for tiny metadata;
- occasional cards.

Avoid building every section inside a rounded rectangle.

This is an invitation, not an application interface.

---

# 16. GLASSMORPHISM

Glassmorphism is allowed ONLY as a supporting material.

Good use cases:
- small countdown;
- floating date badge;
- compact PIX feedback;
- tiny overlays.

Do not use glass cards as the main layout system.

---

# 17. CONTENT PRIORITY

The guest should understand within the first few seconds:

1. Larissa is turning 30.
2. It is a Pool Party.
3. The event is on 22 August.
4. It has a colorful summer vibe.
5. They can confirm attendance through the page.

Secondary information comes later.

---

# 18. EXPERIENCE PRINCIPLE

FUN FIRST.
INFORMATION SECOND.
FRICTION NEVER.

The design should create desire to attend before explaining logistics.

---

# 19. ACCESSIBILITY / USABILITY

Maintain strong text/background contrast.

Do not place essential text over visually complex areas without protection.

Animations must not be required to understand content.

Respect reduced motion preferences during implementation.
